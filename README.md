# Честный розыгрыш для Telegram

Бот для розыгрышей в каналах и группах: как привычные боты розыгрышей, только итог может проверить любой.
Он работает у [@KelLegionBot](https://t.me/KelLegionBot): напиши ему `/give`. Это бесплатно и для всех.

## Как это выглядит

1. Организатор добавляет бота админом в свой канал или группу и пишет ему `/give`. Дальше выбирает чат, приз,
   число победителей, срок и условие: подписку на этот канал и, если нужно, на другие.
   - Приз можно прислать с картинкой, гифкой или видео, а вместо одной строки — свой текст поста: места, ссылки,
     условия своими словами. Бот добавит только кнопку и строку про честность.
   - Срок — дата или «когда наберётся N участников» (но не позже чем через 7 дней).
   - Можно переслать боту понравившийся пост розыгрыша: он предложит сделать такой же и возьмёт из поста
     картинку и текст.
2. Бот публикует пост с кнопкой «Участвовать». Кнопка ведёт в личку бота. Там бот проверяет подписку и выдаёт
   билет: номер и случайный код. По коду участник находит себя в открытом списке.
3. По сроку (или как только набралось нужное число участников) бот закрывает приём и выбирает победителей. Итоги он публикует в том же чате, победителям пишет
   в личку, организатору присылает их контакты.

## Почему нельзя подкрутить

- **Случайное число не наше.** Победителей решает [drand](https://drand.love): сеть «quicknet» League of Entropy
  (Cloudflare, Protocol Labs, университеты и другие) выпускает новое случайное число каждые 3 секунды.
  Заранее его не знает никто, в том числе бот.
- **Номер раунда известен с самого начала.** Бот пишет его в посте при запуске. Этот раунд выходит через
  2 минуты после конца приёма. Если организатор закрыл приём раньше срока, раунд переносится, и бот пишет
  об этом открыто.
  В розыгрыше «когда наберётся N участников» момент конца заранее не знает никто. Поэтому раунд бот назначает
  в момент закрытия приёма: такой, который выйдет позже сообщения с отпечатком списка. Об этом сказано в посте
  и на странице проверки.
- **Список фиксируется до выхода числа.** В конце приёма бот публикует в чате отпечаток SHA-256 списка
  участников. Время этого сообщения ставит Telegram, и оно раньше выхода раунда. Добавить или убрать
  участника после этого нельзя: отпечаток перестанет сходиться.
- **Формула открыта.** Код — в этом репозитории, а сервер показывает тот код, который у него работает
  (`/give/code`).

### Формула (схема `kel-give-v1`)

```
список    = строки "<номер> <код>\n" по возрастанию номера
отпечаток = SHA256(список)
затравка  = SHA256("kel-give-v1|<id розыгрыша>|<отпечаток>|<randomness раунда drand>")
шаг i     : x = SHA256("<затравка>|<i>") как 256-битное число;
            из оставшихся билетов (по номеру) вытягиваем билет с индексом x mod (сколько осталось)
```

Первые шаги дают победителей. Подписку бот проверяет у всех при закрытии приёма, до отпечатка: кто не выполнил
условие, в список не попадает, и это публикуется. После выхода числа никого не перепроверяют, поэтому
организатор не может выгнать неугодного победителя.

## Как проверить итог

- **В браузере.** Кнопка «Проверить честность» под постом открывает страницу `/give/<id>`. Она сама берёт число
  у drand (не у бота), пересчитывает победителей и показывает ✅ или ❌ по каждому шагу.
- **Python.** `python verify.py https://kel-bot.onrender.com/give/<id>` — без библиотек, Python 3.8+.
- **Вручную.** Список (`/give/<id>.txt`), все данные (`/give/<id>.json`) и число drand
  (`https://api.drand.sh/52db9ba70e0cc0f6eaf7803dd07447a1f5477735fd3f661792ba94600c84e971/public/<раунд>`)
  открыты, а формула выше умещается в несколько строк на любом языке.

## Что бот проверить не может

Честно о границах:
- Бот не знает, сколько аккаунтов у одного человека. Твинки отсекаются только условием «подписка».
- Исключение не подписанных при закрытии опирается на ответ Telegram. Сам ответ бот доказать не может, поэтому
  каждое исключение публикуется с номером билета. Происходит оно до выхода случайного числа, так что выбрать
  победителя им нельзя.
- Состав списка виден всем: число участников на кнопке растёт в реальном времени, каждый находит свой код.
  Лишние «призрачные» билеты бот добавить мог бы, но это видно по списку.

## Свой бот

```
BOT_TOKEN=123:ABC PUBLIC_URL=https://твой-сервер python run_bot.py
```

Без библиотек, через `getUpdates`, данные хранятся в `give.db`. Страница проверки открывается на `PORT`
(по умолчанию 8080).

Файлы:
- `give_core.py` — формула и drand;
- `give_verify.js` — та же формула для браузера;
- `kel_give.py` — бот: создание, участие, итоги, страница;
- `give_page.html` — страница проверки;
- `verify.py` — проверка из командной строки;
- `tests/` — проверка формулы на известных ответах.
