Открытый репозиторий «Честный розыгрыш» — как выложить на GitHub

1. Открой https://github.com/new
   Repository name: kel-giveaway
   Public, БЕЗ галочек README / .gitignore / license
   Create repository.
2. Дважды нажми ЗАЛИТЬ_НА_GITHUB.bat в этой папке.
   Он возьмёт свежий код розыгрыша из Кель, проверит формулу и отправит на GitHub.
   Почта в коммитах — безличная (noreply), твоя не светится.

Повторно (после правок розыгрыша) — снова ЗАЛИТЬ_НА_GITHUB.bat.
Ссылку на репозиторий бот уже показывает на странице проверки каждого розыгрыша.
